# Atlet Project Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up a React Native + TypeScript iOS app with a working live camera preview on a real iPhone, as the base for shot tracking.

**Architecture:** A bare React Native CLI app (not Expo), using `react-native-vision-camera` for camera access. No ML, no calibration, and no shot logic yet — this plan only proves the camera pipeline works end to end on a real device.

**Tech Stack:** React Native (TypeScript template), `react-native-vision-camera`, CocoaPods, Jest.

---

## Why a real device is required

The iOS Simulator has no camera hardware. `react-native-vision-camera` cannot show a live preview in the Simulator. Task 5 in this plan must be run on a physical iPhone, connected by USB, with a valid Apple ID configured for code signing in Xcode. Tasks 1-4 only need to build and run in the Simulator to check nothing is broken.

## File Structure

- `App.tsx` — root component, renders `CameraPreviewScreen`.
- `src/screens/CameraPreviewScreen.tsx` — requests camera permission, picks a back camera device, renders the live preview or a fallback message.
- `src/camera/hasUsableCameraDevice.ts` — pure helper: is a camera device available.
- `src/camera/__tests__/hasUsableCameraDevice.test.ts` — unit test for the helper above.
- `ios/Atlet/Info.plist` — adds `NSCameraUsageDescription`.
- `ios/Atlet.xcodeproj/project.pbxproj` — bundle identifier and iOS deployment target.

- [ ] **Step 4: Build the camera preview screen**

Create `src/screens/CameraPreviewScreen.tsx`:

```typescript
import React from 'react';
import { StyleSheet, Text, View } from 'react-native';
import {
  Camera,
  useCameraDevice,
  useCameraPermission,
} from 'react-native-vision-camera';
import { hasUsableCameraDevice } from '../camera/hasUsableCameraDevice';

export function CameraPreviewScreen(): React.JSX.Element {
  const { hasPermission, requestPermission } = useCameraPermission();
  const device = useCameraDevice('back');

  React.useEffect(() => {
    if (!hasPermission) {
      requestPermission();
    }
  }, [hasPermission, requestPermission]);

  if (!hasPermission) {
    return (
      <View style={styles.centered}>
        <Text style={styles.text}>
          Atlet needs camera access to track your shots.
        </Text>
      </View>
    );
  }

  if (!hasUsableCameraDevice(device)) {
    return (
      <View style={styles.centered}>
        <Text style={styles.text}>No back camera found on this device.</Text>
      </View>
    );
  }

  return (
    <Camera
      style={StyleSheet.absoluteFill}
      device={device}
      isActive={true}
    />
  );
}

const styles = StyleSheet.create({
  centered: {
    flex: 1,
    alignItems: 'center',
    justifyContent: 'center',
    padding: 24,
    backgroundColor: 'black',
  },
  text: {
    color: 'white',
    textAlign: 'center',
  },
});
```
